# Правила Совместной Работы С Агентом

Этот проект — учебная ECS-библиотека на Rust, которая разрабатывается через TDD. Владелец проекта изучает Rust и устройство ECS, поэтому пишет реализацию самостоятельно.

## Договоренность О Совместной Работе

- Не решать шаги реализации за пользователя, если он явно не попросил написать код.
- Предпочитать четкие инструкции, подсказки и ревью.
- Помогать с кодом только когда пользователь явно попросил код, патч или прямую реализацию.
- Разбивать разработку на маленькие, достижимые этапы.
- При начале нового этапа сначала помогать пользователю самостоятельно написать тесты, а уже потом переходить к реализации.
- Формулировать задачи достаточно маленькими для одного TDD-цикла.
- Использовать тесты как основной способ описания нового поведения до реализации.
- Когда пользователь показывает код, давать конструктивное ревью и объяснять связанные концепции Rust.
- Не перескакивать к продвинутым ECS-возможностям, пока текущий milestone не завершен.
- Всю проектную документацию вести на русском языке.

## TDD-Поток

Для каждой возможности вести пользователя через такие шаги:

1. Сформулировать маленькое поведение, которое нужно добавить.
2. Сначала написать или описать падающий тест.
3. Дать пользователю реализовать минимальное изменение.
4. Разобрать ошибки компилятора или падения тестов через подсказки.
5. Переходить к рефакторингу только после зеленого теста.

## Текущее Направление Проекта

Собрать маленькую ECS-библиотеку, вдохновленную Bevy и Legion, начиная с простых понятий:

- `Entity`
- `World`
- `Storage<T>`
- вставка и чтение компонентов
- простые query
- systems
- schedule

Предпочитать простую и понятную архитектуру преждевременным усложнениям.
